# Sheet Finder

Google Sheetsのシート名をページ内オーバーレイから検索し、目的のシートへ移動するManifest V3拡張機能です。

## セットアップ

1. Chromeで`chrome://extensions`を開く。
2. 右上の「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選び、このフォルダを指定する。
4. Google Sheetsを開き、拡張機能のアイコンをクリックしてオーバーレイを開く。
5. 必要に応じて`chrome://extensions/shortcuts`でショートカットキーを確認・変更する。

Googleアカウントへの追加ログイン、OAuth、Google Sheets APIは使用しません。現在アクティブなGoogle Sheets画面のシート名だけを読み取ります。

## 使い方

- 拡張機能のアイコンをクリックするか、設定したショートカットキーを押すとオーバーレイが開きます。
- 開いた時点で検索欄にフォーカスされ、入力するとシート名を即時に絞り込みます。
- 空の検索では、現在シートの直前に開いていたシートが最初に選択されます。有効な履歴がない場合は現在シートが選択されます。
- 完全一致、先頭一致、中間一致の順に表示します。
- 候補をクリックするか、`↑` `↓` と`Enter`でシートへ移動します。
- `Esc`、背景クリック、右上の閉じるボタンでオーバーレイを閉じます。
- 更新ボタンでシート一覧を再取得できます。

## 確認方法

自動テストは次のコマンドで実行できます。

```bash
npm test
```

Chromeでは、次の項目を確認してください。

- 空の検索で全シートが表示される
- 完全一致、先頭一致、中間一致の順になる
- マウスとキーボードでシート移動できる
- AからBへ移動して開くとA、BからAへ戻って開くとBが選択される
- Sheet Finderを閉じたままシートタブを直接操作しても、直前のシートが次回の初期選択になる
- 直前のシートを削除または改名後に開くと、現在シートが選択される
- 検索文字を入力すると、絞り込み結果の先頭が選択される
- シート移動後にオーバーレイが閉じる
- ショートカットキーと拡張機能アイコンでオーバーレイを開閉できる
- `Esc`、背景クリック、再度のショートカットキーで閉じられる
- シートを追加・改名した後、更新ボタンで一覧が変わる
- Google Sheets以外のタブではオーバーレイが表示されない
- タブバーに表示しきれないシートも「すべてのシート」メニュー経由で表示される

## 制限事項

- 現在アクティブな1つのスプレッドシートだけが対象です。
- 直前シートの履歴は同じGoogle Sheetsページを開いている間だけ保持されます。再読み込み、別タブ、別スプレッドシート、ブラウザ再起動はまたぎません。
- セル内容検索、複数スプレッドシート横断検索、ローマ字変換、打ち間違い許容は対象外です。
- Google SheetsのDOM構造が変更された場合、`src/sheets-adapter.js`のセレクタ更新が必要になる可能性があります。
